# MONO

A charting-first technical analysis workspace.

## UI direction
- Deep Ocean visual identity
- Compact density
- Left navigation rail and watchlist
- Chart-edge drawing toolbar
- Dockable and floating inspector
- Independently collapsible side panels

## Scope
Charting and technical analysis only. Order placement and broker integration are out of scope for the initial release.

## Development
The first milestone is a React + Vite UI foundation with illustrative market data.
